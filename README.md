# Shikimori API

**Выполнила:** Просветова Ева Николаевна
**Группа:** ПИКД 5 подгруппа

## API
Использован **Shikimori API** (shikimori.one).
Открытая энциклопедия аниме и манги. Ключ API не требуется.

## Функционал
- **Список аниме:** Отображение популярных аниме с постерами, рейтингом и типом.
- **Поиск:** Поиск по названию (debounce 500ms).
- **Пагинация:** Постраничная навигация (Стр. 1, 2...) внизу экрана.
- **Детали:** Большой постер, рейтинг, статус, эпизоды, жанры и описание.
- **Избранное:** Отдельный экран для сохранения понравившихся тайтлов.

**Бонусы:**
- [x] Debounce поиска (500мс через Job + delay)
- [x] Экран Favourites как отдельный роут
- [x] Пагинация (постраничная навигация с кнопками)

## Как запустить
1. Открыть проект в Android Studio.
2. Запустить :)
